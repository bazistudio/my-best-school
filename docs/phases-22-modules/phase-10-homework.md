# Phase 10: Homework, Assignments & Learning Materials

## 1. Domain Overview
Daily academic assignments, digital learning resources, submissions, and teacher feedback.

## 2. Key Responsibilities
- **Assignment Distribution:** Subject-specific homework tasks, instructions, deadlines, attachments.
- **Student Submissions:** Status tracking (Pending, Submitted, Late, Graded).
- **Teacher Review:** Marking, constructive comments, resubmission requests.
- **Resource Repository:** Class notes, syllabus documents, reading recommendations.

## 3. Directory Layout
- Backend: `backend/src/modules/homework/`
  - `homework.routes.ts`
  - `homework.controller.ts`
  - `homework.service.ts`
  - `homework.repository.ts`
  - `homework.schema.ts`
  - `homework.types.ts`
- Frontend: `apps/web/src/features/homework/`
  - `components/AssignmentCard.tsx`
  - `components/HomeworkFeed.tsx`
